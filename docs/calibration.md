# calibration.py

`calibration.py` is pure data, no functions at all, just the ECLIPSE-specific numbers that the general engine logic needs as example defaults. It holds `PFLDH_INTERFACE = [1, 2, 11, 12, 15]` (the binder-local positions that actually contact PfLDH, ECLIPSE's malaria target, straight out of the RFdiffusion design), `PENALTY_PER_ACIDIC = 0.8` kcal/mol (the per-residue electrostatic cost `liability.py` charges for an unprotected acidic residue), and an `ANCHORS` dict holding the two real ECLIPSE binder sequences with their documented liability counts, penalties, and experimental signal outcomes. If this engine ever gets ported to a different LOCKR system, this is the one file that gets replaced wholesale; nothing elsewhere hardcodes these values.

`PENALTY_PER_ACIDIC` isn't a measured biophysical constant, it's a two-point calibration: the charged original binder (6 flagged residues, documented penalty 4.8 kcal/mol) divided by 6 gives 0.8, and the optimized binder (0 residues, 0 penalty) confirms the intercept. With only two data points there's no real curve fitting happening, and the file itself carries a TODO to recalibrate once more LOCKR systems have binding data. Worth knowing too: the `ANCHORS` dict is reference and test data only, nothing in `liability.py` reads it. The engine recomputes liability counts and penalties from scratch by scanning the sequence, so if you ever update a sequence in `ANCHORS`, nothing will automatically keep it in sync with what `scan_liability` actually computes on the new sequence.
