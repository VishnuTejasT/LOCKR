Fold-Change Calculator

This calculator will predict how much brighter the LOCKR system will get when its target is present, while also providing insights on how to improve it.

Read this first if you're new to these terms!!!
Fold-change
The whole point of the sensor: signal with target ÷ signal without target. 1× means no response; 10–50×+ is a strong, easy-to-read sensor.
K_CK — nM, cage–key affinity
This is how tightly the key attaches to the cage. The lower the value, the tighter the binding, and the brighter the signal This can be obtained fromt he scanner tab in this tool!
K_open — Cage-Looseness
This is how often the cage's latch opens on its own, when the stimuli is not present. ~0.001 means it's shut 99.9% of the time (low background noise).
Pull strength — no units
This is how much the target binding will open the cage. Pull = 10 means target makes the cage ~10× more likely to open, while Pull = 1 means there won't be any change to the cage's ability to open. Fit this from a wet-lab titration.
lucKey — nM, the key's concentration
This is a choice for the experimenter. The more key there is, the more signal you'll get, but there is a limiting factor at play.
What limits it?
This calculator will tell you whether the key side (lucKey / K_CK) or the cage side (K_open) is interfering with fold-change abilities, so you know which variable to modify.
